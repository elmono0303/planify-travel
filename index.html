Arquitectura del Proyecto Planify

Patrones y principios aplicados en Fase 1 y Fase 2 (Vanilla JS)

1. Consumo Asíncrono de APIs con `fetch` y `async/await`

En lugar de usar callbacks anidados o promesas complejas, la aplicación implementa funciones asíncronas limpias con bloques try...catch...finally. Esto garantiza que la interfaz mantenga el control del estado de carga (loaders y skeletons) y gestione cualquier eventualidad de red sin congelar el hilo principal de JavaScript.

2. Delegación de Eventos en el DOM

Al renderizar más de 200 países dinámicamente, asociar un addEventListener a cada botón saturaría la memoria del navegador. Siguiendo las mejores prácticas senior, se implementa Event Delegation en el contenedor padre #countries-grid, interceptando los clics mediante e.target.closest('[data-action]') para gestionar el clima y los favoritos con un único listener.

3. Persistencia en `localStorage`

Los destinos favoritos se sincronizan en el almacenamiento local del navegador mediante serialización JSON (JSON.stringify / JSON.parse). Se emplea una estructura de Set en memoria para operaciones O(1) de adición, eliminación y verificación instantánea.

4. Interpretación de Códigos Meteorológicos WMO

La API de Open-Meteo retorna códigos WMO numéricos (0 a 99). Un diccionario centralizado en app.js traduce estos códigos a condiciones semánticas en español, asignando íconos visuales y recomendaciones lógicas para viajeros.
